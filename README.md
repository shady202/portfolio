# Shady Ehab Assad - Portfolio

Next.js 14 + Tailwind portfolio.

## Run

```
pnpm install
pnpm dev
```

## Contact form

Set `EMAIL_USER` and `EMAIL_PASS` (a Gmail app password) in `.env.local` so the form can send mail to the address in `app/actions.ts`.

## Edit content

All portfolio text lives in `app/page.tsx` (data arrays at the top) and `components/hero-section.tsx`.
